
# PokeData Platform

Projeto de Engenharia de Dados desenvolvido com foco em construção de pipelines, processamento de dados, modelagem analítica e visualização de indicadores utilizando dados do universo Pokémon.

---

## Objetivo

Construir uma plataforma de dados ponta a ponta aplicando conceitos modernos de Engenharia de Dados, incluindo:

- ingestão de dados via API;
- processamento e transformação de dados;
- modelagem analítica;
- orquestração de pipelines;
- armazenamento estruturado;
- criação de KPIs e dashboards.

---

## Tecnologias utilizadas

- Python
- SQL
- Apache Airflow
- Power BI
- Docker
- APIs REST
- Git/GitHub

---

## Estrutura do projeto

- Ingestão de dados
- Processamento e transformação
- Data marts
- Modelagem analítica
